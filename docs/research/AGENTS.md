# 연구 문서 영역 에이전트 규칙

root [AGENTS.md](../../AGENTS.md)와 함께 따른다.

- 관찰된 사실, 가설, 예상 결과를 명시적으로 구분한다.
- novel / first / no prior work 및 같은 의미의 표현은 문헌 근거 없이는 사용하지 않는다.
- CVE 분석을 proposed InodeFence logic으로 옮기지 않는다. 알려진 사례의 분석과 generic 설계를 구분한다.
- 선행연구 메모는 paper claim이 아니다. 검토 없이 논문 주장으로 승격하지 않는다.
- 연구 주장에는 확인 가능한 출처 또는 기록된 실험 근거가 필요하다.
- Security Contract 정의 변경 시 [security-contracts.md](design/security-contracts.md)를
  canonical source로 유지하고, 연결된 설명과 테스트도 갱신한다.
- 아직 확인되지 않은 finding의 공개 여부는 [SECURITY.md](../../SECURITY.md)를 따른다.
