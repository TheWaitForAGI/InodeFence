# 회의 기록

## 이 폴더는 무엇인가

논의 과정과 후속 작업을 기록한다.

## 입력

회의 안건, 의견, 확인한 자료.

## 출력

날짜별 논의 기록과 담당 작업.

## 책임

예: ‘signature 정규화 후보를 다음 회의에서 비교’처럼 미결 항목을 명시한다.

## 하지 않는 것

논의 중인 제안을 확정 설계로 취급하기.

## 다른 모듈과의 연결

확정 결정은 [DECISIONS](../../DECISIONS.md), 단계 변경은 [STATUS](../../STATUS.md), 상세 설계는 [design](../design/README.md)에 반영한다.

## 현재 상태

회의 노트는 아직 없다.

## 파일 배치 규칙

날짜와 주제를 식별할 파일명에 결정·미결·후속 작업을 구분한다. 확정 설계의 긴 본문은 링크한다.
