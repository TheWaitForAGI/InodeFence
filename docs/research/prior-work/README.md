# 선행연구 근거

## 이 폴더는 무엇인가

문헌별 근거와 InodeFence의 비교 분석을 둔다.

## 입력

논문 원문, 서지 정보, 정확한 출처.

## 출력

기존 연구가 다루는 것과 검증이 필요한 차이의 기록.

## 책임

예: hardlink가 기존 연구에 등장하면 해당 근거와 적용 범위를 함께 적는다.

## 하지 않는 것

출처 없이 ‘최초’라고 주장하기, 구현 성능 결과 저장.

## 다른 모듈과의 연결

비교 결론은 [related-work-positioning](../design/related-work-positioning.md), 검증 계획은 [연구 질문](../design/research-questions.md)에 연결한다.

## 현재 상태

문헌별 노트는 아직 없다. 현재 포지셔닝은 design 문서에 있다.

## 파일 배치 규칙

문헌별 파일에 출처·관련 부분·관찰·해석을 구분한다. 같은 비교 결론을 여러 파일에 복사하지 않는다.
