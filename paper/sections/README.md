# 논문 섹션

논문 본문의 섹션별 초안을 둔다.

예:

- Introduction
- Background / Related Work
- Design
- Implementation
- Evaluation
- Discussion
- Limitations

연구 메모를 그대로 옮기는 위치가 아니다.

검증되지 않은 예상 결과와 실제 실험 결과를 문장에서 명확하게 구분한다.
